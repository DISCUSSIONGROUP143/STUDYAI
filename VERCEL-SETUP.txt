STUDYAI VERCEL SETUP

The Vercel Telegram publish endpoint is:
  /api/publish-owner

Required Vercel Environment Variables:
  TELEGRAM_BOT_TOKEN
  TELEGRAM_LOG_CHAT_ID
  ALLOWED_ORIGIN (optional; set it to the exact deployed Vercel origin if desired)

The Gemini key remains browser-only and is NOT stored in Vercel.

The original Cloudflare Pages Function under functions/[[path]].js is left unchanged.
